# Description
#### 
This piece, as part of my work catalogue, has undergone multiple iterations over the past year.
I now prioritize designs which seem achievable through diagrams and are easy to refold.
This structure arose from an idea to graft over a bird base, using larger flaps for the hind legs.
The complexity is rated at 75% citing step 52.
